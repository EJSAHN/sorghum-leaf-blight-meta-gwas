# sorghum-leaf-blight-meta-gwas

Excel-only Python pipeline for a dual-trait ACAT meta-GWAS of sorghum leaf blight.

The workflow takes a phenotype workbook and VCF genotype file, performs phenotype harmonization, SNP quality control, PCA covariate correction, single-trait GWAS for incidence and severity, ACAT p-value integration, lead-locus pruning, approximate 95% credible-set summarization, and incidence-severity concordance analysis. The primary output is a single Excel workbook suitable for Supplementary Data 1.

## Repository description

Dual-trait ACAT meta-GWAS pipeline for sorghum leaf blight. Runs phenotype INT, VCF/SNP QC, PCA covariates, single-trait GWAS, ACAT integration, lead-locus pruning, credible sets, and INC-SEV concordance, exporting all key results to an Excel workbook.

## Inputs

Place the required input files in a local project directory that is **not committed to GitHub**. Example layout:

```text
/path/to/project/
  phenotype.xlsx
  700k.vcf or 700k.vcf.gz
  Sbicolor_454_v3.1.1.gene.gff3.gz   # optional, for candidate genes within 50 kb
```

On Windows, the project directory can be any local folder; using forward slashes in examples (for example, `C:/path/to/project`) avoids escaping issues.

The raw phenotype and genotype files are not included in this repository.

## Install

Use the conda environment file. This avoids Windows installation problems with VCF-processing libraries.

```bash
conda env create -f environment.yml
conda activate sorghum-leaf-blight-meta-gwas
```

## Run

```bash
python src/sorghum_leaf_blight_meta_gwas.py --base-dir "/path/to/project"
```

Optional example:

```bash
python src/sorghum_leaf_blight_meta_gwas.py \
  --base-dir "C:/path/to/project" \
  --phenotype-file phenotype.xlsx \
  --vcf-file 700k.vcf \
  --output-file Supplementary_Data_1.xlsx \
  --n-pc 3 \
  --maf-min 0.05 \
  --missing-max 0.20 \
  --fdr-cutoff 0.10
```

## Output workbook

The script writes `Supplementary_Data_1.xlsx` with these sheets:

1. `Lead_Loci_ACAT`
2. `Candidate_Genes_50kb`
3. `Credible_Set_SNPs_95pct`
4. `Single_Trait_GWAS_TopLoci`
5. `Miami_Concordance`
6. `Miami_Correlations`
7. `Lead_Window_Concordance`

No figures are generated by this repository version.

## Notes

- Lead SNPs are selected from ACAT associations passing BH-FDR < 0.10 and then reduced using fixed 250 kb chromosomal bins.
- Candidate genes are reported only when a Sorghum bicolor v3.1.1 gene GFF file is available.
- The credible-set sheet preserves the current p-value-derived weighting scheme so that the exported workbook remains consistent with the Supplementary Data 1 structure.
