SORGHUM LEAF BLIGHT FINAL CODE v2.0.0
=====================================

This exact source tree is intended for both the audited local revision analysis
and the public GitHub repository. Do not maintain separate edited copies.

Windows convenience scripts:

- powershell/INSTALL_LOCAL_CODE_v2.0.0.ps1
  Copies this exact source to D:\projects without running the analysis.

- SETUP_AND_RUN_LOCAL.ps1
  Creates/reuses the final D-drive analysis project and runs the official GEMMA
  workflow. Raw inputs remain outside GitHub.

- powershell/PUBLISH_GITHUB_v2.0.0.ps1
  Tests the source, archives the pre-revision GitHub state with a tag, updates
  main, and pushes tag v2.0.0 using local Git authentication.

- powershell/INSTALL_AND_PUBLISH_v2.0.0.ps1
  Runs the complete audited local analysis, verifies the reference audit and tests, then performs the guarded GitHub update. GitHub is not modified if the local analysis fails.

The inferential hierarchy is fixed:
  Primary: official GEMMA 0.98.5 LOCO score test
  Confirmatory: official GEMMA 0.98.5 LOCO LRT
  Diagnostic only: official GEMMA 0.98.5 LOCO Wald test

The prior 37-locus result is superseded. Top-ranked regions generated by this
workflow are exploratory unless they pass the prespecified FDR criterion.
